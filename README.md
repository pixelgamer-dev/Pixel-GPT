# Pixel GPT 3.0 — Replit

## Features
- True token-by-token streaming UI using Server-Sent Events
- ChatGPT-style sidebar
- Rename chats
- Persistent browser chat history
- Drag-and-drop image uploads
- Image analysis
- Browser voice input
- Browser voice output
- Markdown rendering
- Syntax-highlighted code blocks
- One-click Copy buttons
- Mobile responsive sidebar
- Animated colorful purple galaxy / space theme
- Coding-focused system instructions

## Run on Replit
1. Create a Node.js Replit.
2. Upload these files.
3. In Secrets / Environment Variables add:
   OPENAI_API_KEY = your OpenAI API key
4. Run.

The API key is only used by server.js and is not placed in browser JavaScript.
